Segment diagnosis

wp segment inspect

Walk a segment's blocks on every replica and report what is wrong where

wp segment inspect <logName> <segmentId> [flags]

Parameters to know

Parameter / type Use and default
--bucket string Storage bucket; pair with --root-path (otherwise discovered on each node)
--from-block int First block to walk (default: the start of the segment)
--max-blocks int Stop after this many blocks per node (default: the node's own bound)
--root-path string Storage instance root path; pair with --bucket

Etcd connection flags: see CLI setup.

Demo

wp segment inspect my-channel 1 --bucket milvus-bucket --root-path milvus/wp --etcd 127.0.0.1:32379 --meta-prefix milvus-prod/woodpecker

Output and interpretation

BLOCK ENTRIES READABLE RECOVERABLE STATUS
- - - - no_local_blocks

Walks local blocks and records to locate damage boundaries; it can report later recoverable entries despite a bad block. no_local_blocks says nothing about shared object integrity. Use actual timestamps/metadata separately; --max-blocks bounds the survey.

Finding or error example 
Block 0: checksum mismatch; entry 50 corrupt; later good entries

wp segment probe

Ask every replica how far it can read a segment

wp segment probe <logName> <segmentId> [flags]

Parameters to know

Parameter / type Use and default
--bucket string Storage bucket; pair with --root-path (otherwise discovered on each node)
--from-entry int Entry to read from (default: the start of the segment)
--max-entries int Stop after this many entries per node (default: the node's own bound)
--root-path string Storage instance root path; pair with --bucket

Etcd connection flags: see CLI setup.

Demo

wp segment probe my-channel 1 --bucket milvus-bucket --root-path milvus/wp --etcd 127.0.0.1:32379 --meta-prefix milvus-prod/woodpecker

Output and interpretation

SOURCE object_storage  SERVED 0-0 (1)  OUTCOME end_of_file  VERDICT served

Actually probes sequential entry reads and stops at a failure or bound. 0-0 (1) means one entry, ID 0. Object storage responses share one copy. Active tail/no local data has unknown final boundary and must not be called a permanent stall; Completed shortfall is compared to metadata. cap_reached is a bound, not EOF.

Finding or error example 
Completed expected 99, replica stops at 49 → short / RedFinding if all fail
