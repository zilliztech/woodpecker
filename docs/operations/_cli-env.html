wp env diff

Compare env / runtime / host / build across all nodes

wp env diff [flags]

Parameters to know

No additional operation-specific flags. Connection settings come from CLI setup.

Demo

wp env diff --strict

Output and interpretation

node-0: (reference)
node-1: identical

Compare build, Go runtime and deployment environment. Differences are evidence to investigate, not automatic data corruption.

Finding or error example 
node-1: DRIFT (...)
node-2: UNREACHABLE (not compared)

wp env show

Show env vars + runtime + host + build for a single node

wp env show <node> [flags]

Parameters to know

Parameter / type Use and default
--section string section filter: env|runtime|host|build|all (default "all")

Demo

wp env show node-0 -o json

Output and interpretation

{"env":{...},"runtime":{...},"host":{...},"build":{...}}
