wp k8s logs

Tail logs from a Woodpecker pod

wp k8s logs <node-or-pod> [flags]

Parameters to know

Parameter / type Use and default
-x, --execute Execute kubectl commands (default: print only)
-f, --follow Stream logs
--kube-context string kubectl context name
--kubeconfig string Path to kubeconfig file
--kubectl string Path to kubectl binary
-n, --namespace string Kubernetes namespace
--since string Only show logs newer than duration (e.g. 1h)
--tail int Number of recent lines to show (default 100)
--wp-cluster string WoodpeckerCluster CR name

Demo

wp k8s logs milvus-woodpecker-0 --namespace milvus

Output and interpretation

kubectl ... -n milvus logs milvus-woodpecker-0 --tail=100

status, logs and scale print plans by default; -x executes. scale targets a WoodpeckerCluster CR, not an arbitrary StatefulSet. Set the correct kube context and namespace. doctor checks local prerequisites.

wp k8s scale

Scale the cluster via kubectl patch

wp k8s scale [flags]

Parameters to know

Parameter / type Use and default
-x, --execute Execute kubectl commands (default: print only)
--kube-context string kubectl context name
--kubeconfig string Path to kubeconfig file
--kubectl string Path to kubectl binary
-n, --namespace string Kubernetes namespace
--replicas int Target replica count (required)
--wp-cluster string WoodpeckerCluster CR name

Demo

wp k8s scale --namespace milvus --wp-cluster wp --replicas 4

Output and interpretation

Scaling wp to 4 replicas...
kubectl ... patch woodpeckercluster wp --type merge -p ...
# Printed plan only; --execute runs it.

status, logs and scale print plans by default; -x executes. scale targets a WoodpeckerCluster CR, not an arbitrary StatefulSet. Set the correct kube context and namespace. doctor checks local prerequisites. This targets a WoodpeckerCluster CR, not a Helm release.

wp k8s status [flags]

Parameters to know

Parameter / type Use and default
-x, --execute Execute kubectl commands (default: print only)
--kube-context string kubectl context name
--kubeconfig string Path to kubeconfig file
--kubectl string Path to kubectl binary
-n, --namespace string Kubernetes namespace
--wp-cluster string WoodpeckerCluster CR name

Demo

wp k8s status --namespace milvus --wp-cluster woodpecker-prod

Output and interpretation

kubectl ... get woodpeckercluster woodpecker-prod -o wide
kubectl ... describe woodpeckercluster woodpecker-prod
# Printed plan only; --execute runs it.

status, logs and scale print plans by default; -x executes. scale targets a WoodpeckerCluster CR, not an arbitrary StatefulSet. Set the correct kube context and namespace. doctor checks local prerequisites. status/scale require an operator-managed WoodpeckerCluster CR. For a Helm deployment without that CR, use kubectl get pods directly.
