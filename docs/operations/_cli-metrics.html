Metrics & scenarios

wp metrics list

List all metric series exposed by a node

wp metrics list <node> [flags]

Parameters to know

Parameter / type Use and default
--filter string Substring filter on metric name

Demo

wp metrics list node-0

Output and interpretation

NAME                                          TYPE     SERIES  HELP
woodpecker_server_logstore_operations_total    COUNTER  6       ...

Prometheus counters are cumulative; compare deltas, labels and time windows. An idle counter alone is not a stall. stuck-read/write require a persistent relevant in-flight operation and no successful/EOF progress for the same log. Some named scenarios remain heuristic or placeholders; absence of findings does not establish a healthy application. See scenario implementation limits below.

Finding or error example 
# No matching metric: check --filter, node build and whether the series has been created.

      --filter string   Substring filter on metric name

wp metrics report

Run scenario-based metrics analysis

wp metrics report [node] [flags]

Parameters to know

Parameter / type Use and default
--interval duration Scrape interval within window (default 1s)
--list List available scenarios
--scenario string Scenario name to run
--window duration Collection window duration (default 30s)

Demo

wp metrics report node-0 --scenario stuck-read --window 30s --interval 1s

Output and interpretation

Result: OK — no findings for scenario "stuck-read"

wp metrics top

Cross-node top-N comparison of a specific metric

wp metrics top [flags]

Parameters to know

Parameter / type Use and default
--by string Metric name to rank by (required)
--top int Show top N nodes (default 10)

Demo

wp metrics top --by woodpecker_server_logstore_operations_total

Output and interpretation

RANK  NODE    VALUE
1     node-0  120
2     node-1  100

Prometheus counters are cumulative; compare deltas, labels and time windows. An idle counter alone is not a stall. stuck-read/write require a persistent relevant in-flight operation and no successful/EOF progress for the same log. Some named scenarios remain heuristic or placeholders; absence of findings does not establish a healthy application. See scenario implementation limits below.

Finding or error example 
# Ranking is by the requested metric value. A cumulative counter is not an interval rate.
Complete command help 
Cross-node top-N comparison of a specific metric

Usage:
  wp metrics top [flags]

Flags:
      --by string   Metric name to rank by (required)
  -h, --help        help for top
      --top int     Show top N nodes (default 10)
