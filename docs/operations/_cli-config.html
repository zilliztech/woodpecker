Server configuration

wp config diff

Compare configurations across nodes

wp config diff [node-a] [node-b] [flags]

Parameters to know

Parameter / type Use and default
--all diff all nodes in the cluster against the first reachable node
--reference string explicit reference node name

Demo

wp config diff --all --strict

Output and interpretation

node-0: (reference)
node-1: identical
node-2: identical

This is server configuration, not client SDK configuration. Compare actual values and failed respondents separately.

Finding or error example 
node-1: DRIFT (1 fields differ)
node-2: UNREACHABLE (not compared)
Error: YellowFinding: config drift detected

wp config show

Show the resolved configuration of a single node

wp config show <node> [flags]

Parameters to know

No additional operation-specific flags. Connection settings come from CLI setup.

Demo

wp config show node-0 -o json

Output and interpretation

{"woodpecker":{"storage":{"type":"service"}}}

This is server configuration, not client SDK configuration. Compare actual values and failed respondents separately.

Finding or error example 
Error: Network: /admin/config returned status 503
