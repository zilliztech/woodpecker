Historical WAL diagnosis

wp diag catalog

List implemented checks, formulas, references and scenario manifests; no source/model queries

wp diag catalog [flags]

Parameters to know

Parameter / type Use and default
--check string Check name or stable ID
--source string metrics|trace

Demo

wp diag catalog --source metrics --check writer-latency

Output and interpretation

Lists the metric, formula, rule and required inputs without querying a source.

The CLI, rules and WebUI share the same canonical check keys.

Finding or error example 
An unknown key is rejected.
Complete command help 
List implemented checks, formulas, references and scenario manifests; no source/model queries

Usage:
  wp diag catalog [flags]

Flags:
      --check string    Check name or stable ID
  -h, --help            help for catalog
      --source string   metrics|trace

wp diag metrics check

Run one check; no implicit execution of other checks

wp diag metrics check <name> [flags]

Parameters to know

Parameter / type Use and default
--threshold float Override this check threshold in native units (Trace durations use ms; error counts allow zero)

Demo

wp --context local diag metrics check writer-latency --window 15m --details all -o json > writes.json

Output and interpretation

A wp.diag/v1 report for the selected Writer timer.

This checks recorded WP client Writer operations. It does not infer application end-to-end latency.

Finding or error example 
Missing source configuration, failed queries and insufficient coverage remain explicit.
Complete command help 
Run one check; no implicit execution of other checks

Usage:
  wp diag metrics check <name> [flags]

Flags:
  -h, --help              help for check
      --threshold float   Override this check threshold in native units (Trace durations use ms; error counts allow zero)

wp diag scenario

Run related Metrics/Trace checks and summarize their unchanged results by WAL step

wp diag scenario <name|all> [flags]

Parameters to know

No additional operation-specific flags. Connection settings come from CLI setup.

Demo

wp --context local diag scenario slow-writes --window 15m --node-id woodpecker-0 --details all -o json > diagnosis.json

Output and interpretation

Independent Metrics/Trace findings summarized by WAL step.

A scenario aggregates check results without a second root-cause engine or automatic cross-source association.

Finding or error example 
Configure at least one required source; checks without a source are skipped.
Complete command help 
Run related Metrics/Trace checks and summarize their unchanged results by WAL step

Usage:
  wp diag scenario <name|all> [flags]

Flags:
  -h, --help   help for scenario

wp diag trace check

Run one check; no implicit execution of other checks

wp diag trace check <name> [flags]

Parameters to know

Parameter / type Use and default
--threshold float Override this check threshold in native units (Trace durations use ms; error counts allow zero)

Demo

wp --context local diag trace check server-append-duration --window 15m --details all -o json > spans.json

Output and interpretation

A source-local report for selected retained append spans.

Sampling, retention and emitted tags bound the evidence. No spans does not imply zero operation latency.

Finding or error example 
Missing spans or a query budget prevent a full assessment.
Complete command help 
Run one check; no implicit execution of other checks
