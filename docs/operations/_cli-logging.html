Runtime log levels

wp logging get-level

Show current log level of a node (or all nodes)

wp logging get-level [node] [flags]

Parameters to know

Parameter / type Use and default
--all Show log level on all nodes

Demo

wp logging get-level node-0

Output and interpretation

NODE    LEVEL
node-0  info

Runtime logging changes affect this node. Record the old level and restore it after a short reproduction; this is separate from the log metadata command group.

Finding or error example 
node-0  (unreachable)
# In an --all report, inspect each row.

wp logging set-level

Change log level of a node (or all nodes)

wp logging set-level [node] [flags]

Parameters to know

Parameter / type Use and default
--all Set log level on all nodes
--level string Target log level (debug, info, warn, error)

Demo

wp logging set-level node-0 --level debug

Output and interpretation

Log level set to "debug" on node-0

Runtime logging changes affect this node. Record the old level and restore it after a short reproduction; this is separate from the log metadata command group.

Finding or error example 
Error: Usage: invalid log level ...
