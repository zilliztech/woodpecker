Set the example connection and log before running the commands

Complete CLI setup first. Replace the example context, log name/ID, segment, node and storage space with values from your cluster. Check your CLI version and operation help before running these examples.

export WP_CONTEXT=milvus-prod
export WP_LOG=my-channel
export WP_LOG_ID=42
export WP_SEG=7
export WP_NODE=milvus-woodpecker-0
export WP_ETCD=127.0.0.1:32379
export WP_META_PREFIX=milvus-prod/woodpecker
export WP_BUCKET=milvus-bucket
export WP_DATA_ROOT=milvus/wp

w() { wp --context "$WP_CONTEXT" "$@"; }
wm() { w "$@" --etcd "$WP_ETCD" --meta-prefix "$WP_META_PREFIX"; }

Use w for admin-only operations and wm for commands that consume coordinator metadata. Add the authentication/TLS parameters from CLI setup to wm when required. Node URLs/mappings come from the selected context. Output below is illustrative and abbreviated; adapt positions to your actual evidence.
